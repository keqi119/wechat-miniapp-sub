# B1 后台延期闭环施工边界

2026-10-16。主控已批准`apps/api/phase-b-design.md`，本稿记录后台落地顺序；API尚在最终DTO收敛，以下交互不替代正式契约。

本阶段仅已签主合同、尚未实际交车的延期。保留原订阅月数，起租/结束/服务周期整体顺延；车辆和押金保持原方案。逐期费用/补偿由运营明确金额和计算依据，经不同财务人员复核后，客户确认完整报价和AMENDMENT补充协议。客户确认、签署、可信收付、条款生效分开呈现。没有真实客户确认或供应商结果时保持等待，不提供代客确认、支付或标已签。

订单详情增加延期入口，独立读取服务端delivery-delay-context：orderRevision、priorTermsHash、原服务日期/月数、逐期原账单/可信净实收、未知渠道阻断和canCreate。能力缺失或角色不符默认关闭；后续变更与报价全部携带版本/哈希及每次表单生命周期稳定幂等键。

延期管理详情展示版本化报价与每期原值/新值：新起租日为日期输入，月份和车辆/押金只读；新期起止/结束日以服务端返回版本展示，不在前端重写月界。逐期新到期日/新金额/计算依据使用专用行编辑器，不能要求运营手写JSON。真实原值可以明确作为待核对初值，缺失说明保持空；不生成默认补偿、费用、付款成功或资金余额。

资金部分只读展示服务端归属校验后的原Bill/Payment、净实收、重分配/补收/退款清单及阻断理由。已付和未知账单没有改价入口。新资金结果只来自服务端回读；不从客户端减法宣称可抵扣、可退款或已核清。财务复核针对同quoteHash且不能自审，普通签章审批与资金复核分开。

AMENDMENT使用专用策略、冻结PDF/摘要、双人用印审批和既有租约恢复。准备签署只进入复核，客户确认等待状态无后台替代动作；签署结果只读，不驱动主合同正常建单状态。最新有效协议与原主合同并列展示，旧PDF/quote留历史。延期生效动作的能力与阻断均由服务端提供，实际交接日期再次变化必须重新出版本。

产品代码优先新增独立delay模块及专用组件，最小接入导航、订单入口与签章kind。A阶段usage/credit规则和原测试文件保持不动；不接B2/B3或增加免费换车假记录。实施测试覆盖：固定只读边界、精确分金额、版本/稳定请求键、能力和动作角色、财务非本人、safe投影无敏感字段、AMENDMENT不误标主合同、状态/资金未知不假成功。最终运行本包tests/typecheck/build，不触碰API测试库和生产。
