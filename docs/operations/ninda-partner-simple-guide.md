# 合作商简化办理指引

版本 v2.3，2026-10-28。已上线，[发布记录](../evidence/ninda-partner-simple-v23.md)。

同日已上线[保存与中文名称修复](../evidence/ninda-partner-agreement-save.md)：比例支持填写80或80%，已有乱码文件名刷新后恢复显示，无需重新上传。

平台管理员和运营人员直接办理，不需要配置合作经办／复核分权。合作商的公司管理员是只读查看身份，不在“系统设置 → 新增账号”里建立后台角色。

## 运营登记合作

1. 打开[后台“合作商管理 → 合作商档案”](https://admin.evsub.ndacar.com/#partners)，选择已有合作商或新增主体。若仍见旧界面，刷新后台后进入此地址。新增只需名称；企业／个人类型按实际选择，其他信息选填。
2. 在详情“处理概览”点击“登记合作协议”，上传线下协议 PDF 或图片。
3. 填写**合作商分润比例**并勾选车辆，点击“保存有效协议”。比例可填80或80%，由运营依据约定填写，系统没有20%或80%的默认值。0%有效，空值不算0%。保存未成功时，原因显示在按钮上方，已填内容保留。
4. 协议名称、编号、日期、备注等均选填；未填日期表示系统不额外限制期限。资料未齐可保存草稿，草稿不影响已有有效版本。

同一辆车已有另一份有效合作关系时，系统显示现有归属；确认替换后才能保存。协议更新保留版本，已经成立的订单继续使用原协议和比例。公司管理员未开通、未绑定，不阻断合作登记和客户下单；车辆、产品、保险、订单本身仍按对应业务条件办理。

## 设置公司管理员

1. 在同一合作商详情找到“公司管理员”，填写手机号码，姓名选填。
2. 点击“生成邀请码”。复制页面中的邀请码和[企业服务入口](https://sign.evsub.ndacar.com/owner/)，交给对应人员。系统不会自动发邀请短信。
3. 邀请码有效7天，首次生成时展示。关闭后不能查看原明文；需要时重新生成，旧码立即失效。
4. 本人在服务号“企业服务 → 合作商中心”选择首次绑定，输入手机号及邀请码，核对公司名称，确认绑定后进入。

之后本人可用短信验证码登录。一个手机号可分别绑定多家公司，通过“绑定其他公司”逐一确认，登录后切换。换管理员会立即撤销旧手机号在本公司的访问，新号码须确认绑定；停用也立即生效。不要为此创建小程序客户账号或后台员工账号。

## 查看车辆和分润

企业服务只保留“合作概览、车辆、分润”三个部分；合作商不能修改后台资料。车辆显示实际状态，分润支持日期、协议、车型、车辆组合筛选及分组，历史流水按原订单快照展示。

**净实收租金 = 成功收到的租金 − 已成功退回的租金；合作商分润 = 按该订单冻结比例计算的净实收份额。** 押金和额外费用不计入。退款计入实际成功退款期间，因此某期间可出现负数。分币舍入随累计退款调整，全退时该笔分润归零。

统计是计算结果，不代表已经向合作商转账。无流水显示0；读取失败显示错误；历史数据缺少可信快照或成功时间会单独提示未纳入条数，不猜算补齐。后台和企业服务使用同一统计口径。
