# 订单申请办理指引

在后台“订单管理 → 订阅申请 → 查看详情”查看办理进度。页面顶部显示当前阶段、当前阻断事项和下一步操作；“审核中”是申请整体状态，具体待办以进度区为准。

## 办理顺序

1. **受理**：开始办理申请。受理不等于审核通过。
2. **审核准备**：身份与驾驶资格、信用核验可以并行。信用核验有效后，即可生成待审方案，不必等待资格审核完成。资格、信用和当前候选方案都准备好后进入本单风控。
3. **本单风控**：在“方案风控”审核当前版本。资料、信用或方案变化后，旧结论不能继续使用，按页面阻断提示重新办理。
4. **客户确认**：风控通过后，由客户本人在小程序确认当前方案。后台展示等待状态；此时尚未形成正式订单。
5. **正式订单**：客户确认后可从进度区进入关联订单，继续办理线下合同、支付及车辆交还。

## 身份与驾驶资格有效期

进入“客户资料”，核对分类上传的身份证正反面和驾驶证后，可直接沿用现有附件提交资格资料。两项证件分别选择“有效期至某日”或“长期”。固定有效期只填写年月日；截止日当天全天有效。选择长期后不再填写截止日期。

资格资料提交与审核是两个步骤。提交人或材料上传人不能审核同一版本；页面会显示待其他具备权限的人员独立审核。其他运营人员在同一“客户资料”分区办理。实名核验成功不等于驾驶资格审核通过。

## 按钮反馈

- 操作成功后显示已完成的具体动作，以及刷新后的进度。
- 若操作已成功、最新状态暂时读取失败，页面保留“已提交”提示；先刷新核对，避免重复提交。
- 要求补件后先核对客户补充材料，再点击“继续审核”。
- 若显示版本已变化，核对最新资料后再决定是否提交；不要沿用旧版审核结论。
