# 订单统一办理指引

界面版本：`20261030-admin-workspace-v1`，2026-10-30 01:38（北京时间）已发布。

从“订单管理 → 正式订单 → 详情”进入。本单使用整页工作区：左侧显示主流程与当前节点，右侧显示下一步、办理岗位和未满足的条件。点击流程节点可查看该阶段，点击“回到当前阶段”回到正在办理的位置。

| 节点 | 当前页面办理内容 | 完成依据 |
| --- | --- | --- |
| 申请审核 | 查看原申请、已确认方案及客户资料 | 本次方案已经客户确认并形成正式订单 |
| 合同归档 | 建立本单档案，准备打印文件，上传真实签署原件，提交独立复核 | 当前有效合同与本单条款一致，反馈已处理 |
| 首期资金 | 查看本单账单、支付与退款；财务核对异常到账 | 首期租金与约定押金实际净有效到账，处理中交易和异常已核清 |
| 交付 | 派发现场任务、查看查验记录、办理纸质交车单、确认完成交车 | 现场真实采集、客户本人确认、纸质单归档及实时交付条件全部满足 |
| 用车 | 查看实际起租、里程账户、权益及服务 | 正式交车后建立实际用量账户 |
| 还车 | 安排现场任务，核对实际收车与查验，办理纸质还车单 | 客户确认、归档及真实归还事实核验通过；实际收车不等于正式还车完成 |
| 结算 | 核清里程、账单、退款、争议与必要的终止文件 | 服务端全部结单条件满足后确认完成 |

客户付款和查验确认由客户本人在小程序办理；现场材料由派单员工采集。后台不会用派单、上传、测试付款替代上述事实。取消订单会显示终止结果，不会把尚未发生的交付、用车、还车标记为完成。

材料或资金已补齐但仍处于“待支付”时，可在资金分区使用“重新核对交付条件”。系统重新核对合同、真实到账和车辆等条件，全部满足才转入待交付；未满足会列出阻断原因。该按钮不会扣款，也不完成交车。

合同档案、账单、支付、退款、现场任务、交接及结算优先在本单内打开。需要转到关联档案时，使用顶部“返回本单办理”或“返回上一步办理”回到原记录与办理分区。切换分区会保留已填写内容与滚动位置；切换到另一订单会重新核对资料。

保存成功后读取进度失败，页面会明确提示“已写入，最新进度读取失败”，请刷新核对，不必再次提交。版本冲突或读取失败时，相关提交按钮暂停使用，原输入保留；成功刷新后再核对办理。

其他模块使用相同进度样式，但各自规则保持独立：

- 合同：准备文件 → 签署原件 → 独立复核 → 归档结果。
- 保单：版本资料 → 选定本版原件 → 逐项复核 → 核验结果；已上传附件不会自动成为本版材料，复核通过也不代表保障已经开始。
- 产品：新草稿与已发布版本分开显示，编辑草稿不替换历史订单快照。
- 合作商：协议文件、比例和车辆是合作记录；公司管理员查看账号独立办理，未绑定不阻止有效合作协议使用。
- 现场交接与还车结算：分别显示客户确认、纸质归档、里程和资金条件，并给出对应入口。

## 交付前取消

尚未完成正式交车的线下订单可走取消。进入“订单管理 → 正式订单 → 详情 → 取消订单”办理纸质签署核实；当前核实已提交时，由非提交人、非证据上传人的管理员或运营使用“独立复核取消依据”。

已经实际签署的订单，还需在“取消订单 → 终止协议”建立本单“终止协议”，系统自动关联本单，准备文件、完成客户/出租方/平台三方实际签署、上传原件和保管资料、提交并独立复核归档。已有历史签署归档的订单不能改填“未签署”。

取消依据复核、三方终止归档和资金核对可并行。没有实收款时不用先付款，也不生成退款；有实收时须逐笔成功退清，无在途支付、待批或处理中退款。保单核验和首期租金到账属于交付条件，不是取消前提。

最终在“取消订单 → 确认取消”填写原因并提交。系统会重新核验未正式交付、当前取消依据、有效终止归档、商业条款一致、资料反馈、未结束变更/签署、资金及车辆预留。此前的准备结果不替代最终实时校验。

取消核实不会冻结订单、支付或账单自动发布；必须最终取消成功才会将订单设为已取消、未结束账单作废、权益失效并释放车辆预留。车辆转为未上架，不会自动重新发布。历史合同及收退款记录保留。

## 列表与详情的查看方式

一级列表将标题、同模块导航和新增等主操作放在一行，搜索筛选在下一行；表格自己滚动，表头和分页保留。订单与合同的次级入口收进导航分组，当前列表仍有明确名称。办理说明可从标题旁的信息图标展开。

搜索、状态和页码会保留在地址栏。进入详情后，可使用“返回列表”或浏览器后退返回原筛选和位置。合作商、保单、产品等页面标注“筛选当前页”，只筛选已加载的这一页；如未找到，请调整条件或翻页。

订单、申请、合同档案、保单、产品和合作商等长详情使用整页工作区；左上角可收合主导航。短编辑和上传继续使用抽屉，关闭后回到原分区。小屏通过“切换分区”选择详情内容。合同、保单、产品通过“查看版本”选择当前或历史版本；选择历史版本不会替换当前业务依据。

取消分支依次提供取消概览、签署核实、终止协议、资金核查和确认取消。前三项可并行准备；最终按钮只有满足当前取消条件且人员具备相应权限时可用。页面列出实际未满足条件，点击办理入口可在本单内继续。
