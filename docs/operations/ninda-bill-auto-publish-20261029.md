# 合同账单自动发布操作说明

租金和押金账单由已确认方案生成。系统在账单到期日前3天自动发布，例如11月28日到期的账单，于11月25日进入发布窗口；采用北京时间，正常运行时一分钟内处理。

## 后台查看

进入“月度账单”，查看“发布安排”；也可进入账单详情的“办理条件与进度”，或在订单详情的“资金”分区查看对应计划。

- **自动发布·已安排**：尚未进入发布窗口，按显示日期等待。
- **自动发布·等待执行**：时间已到，下一轮系统扫描自动办理。
- **自动发布·暂缓**：按提示处理合同归档、合同资料反馈、订单变更或归还结算。阻断解除后系统重新核对并自动补发。
- **账单已发布**：客户可从小程序查看并主动支付。发布不是扣款。

租金和押金无需逐期点击发布。系统保留合同当前版本、金额、客户归属、订单状态及归还保护。额外费用、还车结算、超里程等仍按各自专项流程审核办理。

合同归档晚于计划发布日期时，满足条件的账单会在后续扫描补发。系统重启后同样补发，已发布账单不会重复发送待支付通知。

## 上线样例

订单 `cmvt9tqah000enw01xpua97le` 在本次上线前首期账单已经发布；后续账单到期日期为2027年11月至2028年9月。第二期到期日为2027-11-28，自动发布日期为2027-11-25。本次变更沿用订单中已确认的日期和金额。

## 运维

生产需显式设置 `BILL_AUTO_PUBLISH_ENABLED=true`。切版先以false完成数据保全，再在维护窗口独立启用。系统每分钟输出安全扫描结果 `BILL_AUTO_PUBLICATION_SCAN`，只包含数量、时间和停止状态。

成功发布留下 `SYSTEM / billing-scheduler / AUTO_PUBLISH` 审计，记录计划日期、到期日期和执行时间，同时创建一条站内通知。业务阻断等待下一轮；异常日志不包含客户信息或凭证。核验需以完整扫描 `stopped=false` 为准。
