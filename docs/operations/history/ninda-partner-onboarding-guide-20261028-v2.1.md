# 合作商经办关系与准入操作指引

更新：2026-10-28。本指引说明现有后台入口，不代表任何企业已经授权、资料已经核对或审核已经通过。

## 先分清两个下拉框

| 下拉框 | 所在操作 | 候选来源与含义 |
| --- | --- | --- |
| 已注册账户 | 提交本人或经办关系 | 本人先在小程序登录形成的客户账户，不是后台管理员账户。候选不按企业或其他绑定排除；同一真实经办人分别取得授权后，可以绑定多家企业。 |
| 已核验身份关系 | 提交准入核验 | 仅列出当前合作商已经复核通过的本人或经办关系。没有通过的关系时为空，不能直接选择登录账户代替。 |

实名核验说明个人身份，不等于企业经办授权。后台管理员的办理权限、账户手机号匹配、营业执照上传也都不自动证明企业授权。企业经办人与授权依据须逐家核对；个人主体须核对本人关系。

## 第一步：提交本人或经办关系

1. 打开“合作商管理 → 合作商档案”，找到该企业，点击“查看办理”。
2. 点击详情顶部的“提交本人或经办关系”，表单在“处理概览”展开。
3. 在“已注册账户”选择实际本人或经办人的账户。本人尚未登录注册时，先由本人完成小程序登录；不要新建虚假客户或使用管理员账号冒充。
4. 上传清晰的真实身份及经办授权依据。实际核对本人和权限后，才能勾选“已现场核对本人及经办权限”并提交；缺材料时先补材料。
5. 由另一位实际工作人员使用其有权限的管理员或运营账号，进入同一合作商的“详细资料 → 本人或经办关系”，点击“复核身份关系”。提交人和材料上传人不能审核本人材料；换用账号不代替真实独立复核。

关系已提交但尚未复核时，先完成第5步，不必重复提交。复核通过后，回到详情顶部办理准入。其他企业按同样步骤分别办理，不能把一家企业的关系当作另一家的授权。

## 第二步：提交准入核验

点击顶部“提交准入核验”，在“处理概览”的“已核验身份关系”选择刚通过的当前企业关系。上传准入材料，按实际情况核对身份、车辆权属及企业营业执照后提交，再由另一位符合独立复核要求的工作人员点击“复核准入材料”。

如果“已核验身份关系”仍为空，先到“详细资料”检查关系状态；未提交时回到第一步，已提交时等待独立复核。主体资料变更可能使原关系失效，需要重新核验。

如果空的是第一步的“已注册账户”，查看字段下方是否有加载或权限错误，并在客户档案核对本人账户。该下拉目前读取最近100个客户，尚无搜索翻页；超过范围或加载失败应交由运营排查，不是“账户已被其他企业占用”。

## 后续顺序与边界

准入通过后，办理“提交车辆权属 → 详细资料中的确认车辆权属”，再通过“办理合作协议归档”建立档案、真实签署、上传并独立复核。之后在“分润规则”办理真实约定及独立复核。

三家合作期已确认是2026-10-28至2031-10-27（含起止日）；平台按月租20%收取服务费，但计提基础仍留空、待双方确认。合作期不自动成为授权期、分润规则有效期或客户租期，不用“待定”填充字段形成生效规则。

车辆和产品发布不替代合作准入、权属、合作归档与已核准分润规则；这些条件共同决定能否申请。保单审核及保障条件在交车前检查。合作商收款账户不是申请的前置，在编制人工结算单前才须完成账户独立复核。

本指引对应现有合作商详情、线下合同档案和分润界面；不新增客户自助绑定入口，不代本人登录、授权、签署或审批。
