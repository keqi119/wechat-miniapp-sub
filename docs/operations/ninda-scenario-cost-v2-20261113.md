# 宁达经营场景成本 v2 发布记录

发布标识：`20261113-scenario-cost-v2`。

## 变更范围

经营场景采用四列背景、三列成本卡片，区分随车辆、企业固定、业务营销费用。增加产品期限、复购订单占比和坏账率；各分组采用自身期限。新场景保存为 v2 JSON，旧参数与历史快照保持冻结，无数据库结构迁移。

一次性牌照/投放成本仅按逐车未来需要计入；退出处置仅扣退出残值一次。固定推广按预算折算月投入持续计入，新客与复购费用按订单占比分开。BaaS/保险真实期间优先，缺覆盖预算保留来源。收入展示应收、坏账损失与预计实收；保本及目标价同步考虑坏账。

接口与操作说明见 [API 约定](../api-contract.md) 和 [定价参考说明](../product-pricing-reference.md)。
