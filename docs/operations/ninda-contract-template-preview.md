# 合同模板正文预览与当前入口

2026-10-30，后台静态版本`20261030-contract-preview-v1`已上线。

“合同管理 → 模板与文案 → 模板详情 → 详细资料 → 正文”统一按合同样式显示：标题居中、章节加粗、分条分段、表格和重点文字按原稿排版。结构化模板只展示正文，签署方配置JSON及转义换行不进入阅读区。模板变量保留，逐单生成时填入订单事实。

本次检查线上全部14个版本（7个结构化正文、7个普通文本），包括订阅合同、终止协议、合作协议、交还车单、用户协议、隐私政策及配套说明。正文和发布状态均保持不变；不更新已签文件。

合同导航保留“合同工作台、模板与文案、线下档案、合作协议依据”。移除历史电子合同、历史企业印章、历史用印授权、历史签署策略、历史签署复核和历史技术验收入口；访问旧地址会回到合同工作台，不再加载旧功能的操作页面。原历史数据保留。

验证：16项针对性测试通过；全部14个版本浏览器逐行核对无正文遗漏，1440与390宽度检查通过；6个停用地址均转回工作台且未请求对应旧业务接口。API、FIELD和服务号资源保持原版。见[发布核验](../evidence/ninda-contract-preview-20261030.json)。
