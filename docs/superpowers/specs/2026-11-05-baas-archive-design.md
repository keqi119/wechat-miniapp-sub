# BaaS档案人工验收调整

用户已授权生成计划后直接实施。本轮从已部署 `20261105-addon-products-v1` 冻结源码隔离开发，只改后台/API；小程序体验版仍为1.2.4，OCR不恢复。

## 已确认根因

车辆详情底部BaaS入口没有携带vehicleId；详情、payload和API均只允许DRAFT编辑，导入ARCHIVED记录无编辑操作。已启用合同条款被成本计划、确认、付款及冲正按当前termsHash校验，直接改条款会使历史资金事实失效。合同专用附件仅有上传/读取，没有作废、删除状态。

## 登记、状态与历史

- 车辆详情同页提供登记、修改和合同专用附件区域；打开合同保留车辆范围，查看具体档案保留record及返回位置。
- 以有效中、已过期为主视图；待完善、未到生效日、暂停和归档明确另示，不伪造生效或到期。有效中须真实ACTIVE、基础资料齐全，且上海当日在登记起止日期内；结束日包含当天，结束为空表示长期。
- 保留数据库单车最多一个ACTIVE约束和Vehicle锁。不自动把导入档案设为有效。完整、当日有效且有有效专用附件的DRAFT/ARCHIVED可由人员明确启用；原到期ACTIVE须明确结束后接续，不在读取时改历史状态。
- 允许登记资料修正；非草稿修改须说明。已启用条款不得变为不完整。每次条款变化事务内封存修正前完整条款、termsHash、firstCostPeriod及对应revision区间，更新当前记录并审计；修正不改写原成本计划、付款或冲正。
- 新增不可变VehicleBaasContractRevision表。旧计划按sourceRevision所属区间及termsHash核对原条款并重算；返回对象仍保留当前revision/status/activatedAt以维持CAS及生命周期门禁。新生成始终使用当前条款。原BaaS资料发布条件不加强为必须ACTIVE。

## 附件

- AssetPrivateFile增加voidedAt/voidedBy/voidReason/removedAt/removedBy/removeReason六个nullable无默认列，只允许BaaS产生处置状态。现有文件均保持有效，不回填伪造动作。
- `POST /admin/baas-contracts/:id/files/:fileId/void` 与 `/remove` 接受父revision、idempotencyKey、reason。当前权限、父归属、Vehicle→合同锁、文件ID和动作摘要均须核验；同键回放，换文件或内容不得误回放。
- 作废记录保留列表、原因和作废标签，可从独立history读取路径查看；删除从当前列表隐藏，普通与history路径均不再返回。永久保留绑定、StoredFile和共享磁盘内容，公共/通用文件路径始终禁止读取。
- 当前有效文件才用于启用、新生成成本。旧成本计划没有BaaS附件manifest，人工付款实际使用独立COST证据；不伪称旧附件快照，也不破坏既有资金操作或其它资产文件kind。
- 上传区在卡片内支持拖拽，文件列表直接打开，并提供作废、删除。操作确认和原因、未知响应原命令重试、2xx后只GET回读、401/403清理与迟到结果隔离沿现有规则。
