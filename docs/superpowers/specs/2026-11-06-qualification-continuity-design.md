# 身份与驾驶资格资料更新衔接

用户已确认：相同内容重复上传沿用审核；不同证件图片经核对身份及有效资格后，留痕关联本订单，不因换照片重签合同。按项目已有授权直接施工。

采用保留原审核、追加本单核对记录的方案。不能直接覆盖旧风控摘要，也不能关闭交车资格检查。旧合同、资格版本及签署凭据保持原事实。

- 资格提交保存当前客户资料的语义快照（身份字段摘要、分类证件内容摘要、其他资料摘要）；当前资料仅文件编号、无意义版本变化而内容相同，则继续有效。历史资格通过匹配其原 profileHash 的可信申请/订单快照恢复比较依据，无法证明一致时继续要求核对。
- 保存个人资料时，同一客户同一槽位完全相同内容的重传复用已有文件引用，无实质变化不增版本。文件归属、用途、摘要和资产隔离检查不省略。
- 证件内容变动须新资格审核。最新资格有效后，管理员/运营在本订单确认“仍为同一承租人、已核对原签约资料与当前两证”，填写说明。记录当前资格版本、当前资料内容摘要、原风险凭据和本单版本；不得跨客户、旧版本或无效资格放行。不同姓名/手机号等签约主体变更继续阻断，不通过换照片入口替换承租人。
- 本单核对独立于付款、合同归档、保单、车辆限制，不自动交车。普通资料管理员可审核留痕；其他岗位不得审核本人参与上传/提交的材料。
- 后台紧凑显示待核对原因、原/现证件及现有资格操作，更新核对不增加独立详情层级。客户仅收到适用的资料状态提示。
- 不自动替用户审核本次不同的驾驶证图片。上线后提供实际核对入口供人工完成。

技术决定：新增资格快照可空列及订单资格衔接审计表（追加记录，旧数据不伪造回填）。所有命令使用当前 RBAC、版本比较、订单/客户锁和幂等键；读取不能触发业务写入或渠道请求。
