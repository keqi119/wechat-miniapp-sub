# 本地车辆资料匹配与补录

用户于2026-11-03指定只读来源 `F:\新能源汽车`，要求按逐车文件内容匹配当前系统车辆数据库。既有直接施工授权适用。目标仅当前宁达独立系统，使用受权后台API，不连接旧库。

## 已核实与处理原则

- 来源80个车辆文件夹，全部按当前车牌唯一匹配83辆现有车辆中的80辆；仍以文件内VIN交叉验证，异车资料不因所在文件夹而自动认定。
- 现有主要车辆资产字段均已填齐。本次不重建车辆、不改车辆状态、订单、价格、已批准保险结论或既有合作关系。
- 用原件明确事实核对现有字段，补全空缺；已有非空值与文件冲突时形成待核差异，不以发票金额冒充实际采购金额、不以签署日期替代BaaS首次扣款起月。
- 文件名用于检索和初步分类。身份和业务字段必须引用具体原文及页码；扫描件或不可靠文本列为待核，不猜测。
- 用户随后明确选择“补充资料并归档原件”，授权补齐逐车私密档案入口。已有BaaS/保险/牌照专用文件边界继续按真实父对象使用；统一档案不使用公开相册。
- 保单仅准备来源明确的资料草稿，留存真实起止时间、保费整数分、保障内容和凭据。不能自动审批、激活、触发付款、生成历史成本或签署事实。

## 执行路径

采用既有后台领域命令，而非SQL更新；相比仅凭目录名上传，增加VIN核对与逐字段证据；相比另建主档，保持现有车辆ID和业务关系。

私有清单、原文、差异、请求及回读证据只保存项目忽略目录 `.runtime/vehicle-local-20261103/`，不入Git。执行计划固定来源SHA、目标ID、版本、旧值及稳定幂等键。执行前再次读取，版本或原值变化停止相关操作；失败不更换幂等键盲重试。所有真实写操作由主控执行。

## 原件归档增量

采用独立 `VehicleDocumentFile` 关系复用 `StoredFile` 字节存储，避免把一般证件错误归为某张保单或牌照的业务凭据。相对仅上传通用文件，此方案提供可核验车辆归属；相对改造所有现有专用附件表，此方案保持原有八类父对象规则稳定。

- API：GET/POST `/admin/vehicles/:vehicleId/documents`，GET `/:fileId`下载。仅当前ADMIN/OPERATIONS可访问。列表返回 `revision`（Vehicle.documentRevision）、`vehicleRevision`、`items`。
- multipart上传：`file,revision,vehicleRevision,idempotencyKey,category,sourceRelativePath`。分类固定 REGISTRATION/DRIVING_LICENSE/PURCHASE/INSURANCE/BAAS/PAYMENT/INSPECTION/PHOTO/OTHER。相对路径保留来源目录结构，拒绝绝对路径、上级路径和控制字符。
- 新表字段：fileId主键及StoredFile外键、vehicleId外键、category、sourceRelativePath、sha256、uploadedBy、createdAt；vehicleId+sourceRelativePath唯一，同字节不同路径保留各自原件记录。重复执行使用相同幂等键，不重复挂接。
- 原件支持PDF/JPEG/PNG/DOCX/MP4，单份32MiB；当前来源最大约20.8MB。校验真实文件头/格式，保存原始字节，不转换或重压签署文件。下载私密、不缓存、nosniff并以附件方式提供。
- 上传锁车辆、核对当前工作人员和双版本；新增文件只增加documentRevision，车辆业务revision、状态、里程、订单和相册均不变。文件、关联、版本、审计、幂等同事务；失败中止并保存检查点。
- 通用后台/客户/公共文件以及跨域引用检查同时检查专用映射，不能通过修改用途或塞入媒体ID绕过权限。
- 后台逐车显示原件列表、分类/相对路径、大小、下载及上传；无权限不读取。上传冲突或刷新失败保留输入并说明状态。
- 不导入Thumbs.db；无法归属单车的根目录文件保留在来源与报告，不随意关联。原件文本存在异车VIN的文件进入待核，不能仅凭目录位置写入。

## 批量执行核验补充

慢网环境中，全部原件仍通过上述授权API上传；每车完成后，在固定新平台主机与版本上只读查询文件绑定，并直接读取实际存储字节核对SHA、长度及文件读取期间的稳定状态。数据库不执行业务写入，路径逐层禁止符号链接；工具、来源计划、主机、镜像、挂载目录和回执均以固定摘要约束。每辆车使用独立后台会话，所有会话的管理员身份必须一致；写入结果未知时停止，先按日志对账。

全部存储核验后，再通过真实认证下载抽样检查PDF、JPEG、PNG、DOCX、MP4，包括最大视频和用户确认VIN的原合同；同时验证未登录、通用后台、公网媒体及跨车辆读取均被拒绝。存储字节校验和下载抽样分别记录，不将前者表述为全量下载。
