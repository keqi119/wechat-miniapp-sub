# 保险校验移至车辆交付

依据：用户 2026-11-12 明确要求新购未投保车辆可先上架，实际交付前核查在保。

- 商品单台、批量及车辆商品总开关不再以保险作为发布前提；其余发布检查保持原规则。
- 普通交车和换车的新车交付，在后台办理条件及最终确认事务中，按实际交付时间重新检查交强险、商业险。
- 两类险种均须覆盖实际交付时刻，有已登记或已复核的有效版本及与车辆匹配的可读取、摘要一致的保单原件。未来生效、到期、退保、车辆移出、缺原件、险种不明均不得冒充有效保险。
- 有效时间使用现有上海日期规则，起始包含、截止不包含；无须一次覆盖整个租期。有效替代保单可覆盖同险种失效旧单。
- 缺项在已有交付条件列表内逐项提示并定位车辆保险页；不增加发布页布局或新保险要求管理功能。
- 最终交付保留现有合同、实名、客户资格、资金、交接确认、车辆归属、并发及幂等门槛，并保存实际校验时间及保单版本证据。
- 续期、在租保险提醒和历史保单投影保持现状；本次只调整发布与交付门禁。
- 生产部署只包含已核验的本次差异，保留电子签及自动签开关、认证印章和业务资料；不自动上架车辆、不创建交付或签章。
