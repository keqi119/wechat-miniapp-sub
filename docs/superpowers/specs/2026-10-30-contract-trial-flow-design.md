# 试运行合同与取消流程简化基线

日期：2026-10-30。依据本轮用户指令及已授权的生成计划后直接施工。本版覆盖此前要求协议双人复核、原件保管登记、取消并行准备的基线；资金、身份、保险等非协议审核权限不因此改变。

## 办理方式

合同主流程固定为：**模板按版本启用 → 根据交易条件生成合同 → 预览及打印 → 上传并审核签字版 → 归档**。每次只展开当前办理步骤，前序未完成时不能启动下一步；已完成步骤可回看。版本和历史原件保留。

- 模板由有权限的运营/管理员在后台启用，同类型新版本启用后旧版本停用；已绑定合同固定原版本。启用不要求第二人，确认正文和操作留痕保留。
- 生成读取订单已确认交易条件、产品快照及签署主体，不重新手输单价、期限等。没有确认数据时明确提示缺项。
- 预览打开生成的PDF；运营确认已核对打印内容后进入上传。该确认按档案版本及源文件记录；重新生成后重新确认。
- 签字版上传后登记签署日期、合同编号和页数，审核签署主体、完整性、条款与清晰度。有权限的同一运营可上传、提交及审核；不再采集或要求保管人、保管位置、保管确认项。
- 审核通过进入“待归档”，再明确点击归档；仅真正归档后放行合同依赖业务。审核或归档时重核快照、附件归属与版本，不将上传视为已签署归档。
- 历史已提交/已归档数据保留；不自动批准历史材料，不强迫已提交版本补做预览。新草稿遵守串联门槛。

## 取消订单

按 **确认签署情况 → 必要终止协议 → 资金核查 → 确认取消** 串联。已归档或失效的历史租赁签字合同可直接证明已签，无需重复上传取消依据；没有既有签署事实时由运营一次登记实际签署情况和取消原因，附件选填，不要求他人复核。无法确定签署情况不能继续。

已签订单的终止协议复用上述合同流程；未签自动跳过终止协议。历史矛盾、旧商业条款、未处理反馈明确提示。后续步骤写操作在前序未完成时禁用，已完成步骤只回看。原订单不因查看取消页而冻结。

资金核查自动计算，采用账单/收款/退款分类表格，显示金额、状态、日期，点击对应金额进入记录详情，可返回本单原位置。仍校验在途支付退款、逐笔全退、账单实收兜底、车辆预留及未完成变更；退款实际成功后才计入已退。取消未支付账单不要求客户先付款。
