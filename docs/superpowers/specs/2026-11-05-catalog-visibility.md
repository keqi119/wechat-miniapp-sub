# 下架商品退出公开目录

人工验收：后台只有1个已发布商品，小程序展示4台车辆。线上只读核实：4台Vehicle为PUBLISHED，1条VehicleListing为PUBLISHED且visible，19条WITHDRAWN；仅1车存在active的已发布可见套餐。公开列表和客户首页只按车辆状态取数，空套餐车壳仍被列出，首页take还先于资格过滤。

本轮从已部署baas-save-fix-v1冻结源隔离。列表、品牌、总数、分页、匿名及登录首页推荐统一按有效公开商品来源判断：车辆已激活、整体商品已明确上架，至少一个active套餐绑定正式已发布且可见产品方案，且产品版本、车型范围、冻结摘要和绑定校验通过。采用正向允许规则，待确认、草稿、下架、隐藏及未知方案状态均默认不可进入公开目录。资格过滤先于分页及推荐数量截取。零有效公开方案的新申请详情返回404。

用户继续明确三层动作：原顶部“上架车辆”改为“激活车辆”，只管理Vehicle.status；原卡槽“发布商品”改为“上架产品方案”，只管理单个VehicleListing/SubscriptionPlan；商品展示Tab顶部唯一“商品上架/下架”管理新增Vehicle.catalogPublished。激活与上架方案均不自动打开整体商品开关，普通车辆编辑不得写入该字段。整体上架要求已激活、七项资料条件及至少一项有效公开正式方案；同时校验当前车辆和商品写权限、父版本、幂等、占用及锁定。整体下架只关闭开关，保留原方案、条款和订单。整体商品仍上架时不允许从车辆停用入口绕过，须先商品下架。

旧页面直调新申请也须核对整体开关；成功旧提交收据仍可在当前客户授权下回放。既有申请后续报价、订单、续期和冻结读路径不加全局新条件。上架时的车况披露冻结由整体商品发布掌握。
