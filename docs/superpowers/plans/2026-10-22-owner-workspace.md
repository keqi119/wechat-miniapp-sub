# 法人 H5 工作区 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** 法人清楚区分授权与逐单合同，操作反馈就近，能够从H5明确确认并手签本企业业务合同。

**Tech Stack:** NestJS / Prisma / PostgreSQL，React / Vite，现有法大大 API2。

**Spec:** ../specs/2026-10-22-owner-workspace-design.md

## Review Focus

1. 查询或页面返回不派发签章；手动专用门禁不能打开平台自身或车主自动签。
2. 旧证书/印章/客户资料同意变化，列表与详情不会给出可绕过的手签入口。
3. 用户点击签署后返回，结果未知不能重复创建交易或切自动/手动。
4. 旧渠道撤销异常不丢失撤销意图，当前有效单方授权不受影响。
5. 页面切换、退出、服务端拒绝时，本地反馈不落到另一企业或记录。
