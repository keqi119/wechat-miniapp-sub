# 产品页面与商品发布实施计划

1. 先测基本车况未登记、显式是/否、修改原因、双版本、重放和撤权；实现独立事实表及专属接口，UI 嵌入现车况查验顶部。
2. 先测商品七项 readiness 与事务发布；实现车辆/商品共用核对、真实保险类型/日期、资料补录原因及基本车况披露。删除旧全文车况披露的单独硬条件。
3. 核对既有产品表单、仓库及版本接口，写页面行为失败测试；产品工作台改整页表单，仓库统一列表与状态 Tab，保留旧记录深链、版本与权限。
4. 回归本轮资料卡、导航、保单登记、台账；完成类型、构建、独立本地数据库迁移与关键事务测试。
5. 独立审查全部增量；冻结源与清单，精确合入根目录后按现有系统发布流程交付，不修改小程序和旧系统。
