## 根因和范围

仅修改小程序 API 展示适配器及用车页。区分首次待签约/待支付/待交付、已交付、换车空档、还车结算和旧接口缺省字段。没有权威换车证据时不提示换车；没有真实分配时不声称已交付。合同列表入口不声称合同已可签。金额、订单状态及交易校验不变。
