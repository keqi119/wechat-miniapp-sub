# 资产资料、BAAS与内部成本后台实施计划

日期：2026-10-31。基于已授权的后台重做与 `2026-10-31-vehicle-assets-design.md`，只实现已落地的真实接口，不新增空菜单。

## 页面范围

车辆详情增加独立资产资料区：电池归属、首次登记日期、备注，未知明确显示未登记。资产版本与车辆版本分别提交；财务只读最小资产事实，运营可保存。型号年款、车辆年份、首次登记日期分别呈现。

车辆管理增加 BAAS 合同入口，财务管理增加内部成本计划与成本台账。运营只看 BAAS 计划；财务及管理员可确认成本。BAAS 列表、详情、草稿、专用文件、启用/暂停/恢复/终止/归档和周期生成形成完整闭环。折旧与牌照待对应后端完成后独立接入，不预先放无效入口。

## API与数据契约

以实际 controller、DTO 和服务显式投影为准，开始前与后端实现者锁定列表、详情及 preview 字段。新模块统一使用 api.request 的会话、CSRF、错误处理；不调用公共文件接口上传资产凭证。金额在表单边界从元严格转整数分；日期原样 YYYY-MM-DD，不能由浏览器时区改日。

- profile PATCH：revision、vehicleRevision、idempotencyKey；只改明确填写的资料。
- BAAS 草稿 create/update：按服务 DTO，创建关联明确车辆并携带 vehicleRevision、assetRevision；状态走独立命令，不能 PATCH status。
- cost-preview 只读；按服务端返回显示完整周期、费用、付款日、已有计划、跳过状态和 warningIds。所有警示逐项确认后才允许生成。
- cost-plans 生成带原范围、revision、previewHash、acknowledgedWarningIds、稳定幂等键。范围/文件/合同变化清空旧预览。409保留填写内容，禁用旧确认并提示重新读取和试算。
- 财务确认选择具体 SCHEDULED 计划及每条 revision，展示服务端每笔分金额和合计；显式命名“确认成本入账”。不以通用“保存”隐式入账。
- 已确认金额只读；锁定/冲正需原因，锁定不提供解锁；人工付款必须本成本专用证据、实际日期、参考号和说明，金额等于原成本。显示“人工付款登记”，不得标成渠道支付成功。撤销登记需原记录版本及成本版本，不制造退款事实。
- 专用附件上传后父版本增加，必须回读后再启用/生成/办理；不复用上传前版本。下载仅用服务器返回的所属资源专用路径。
