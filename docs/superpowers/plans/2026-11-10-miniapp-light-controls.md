# 首页与选车页轻量操作样式 Implementation Plan

> 按用户指定方向直接实施；主控实施，独立只读审阅。纯视觉修改复用现有业务测试，以真实模板渲染核验为主。

**Goal:** 减少首页、选车页及底部导航的大面积深色和高饱和填色，使内容与车辆图片成为视觉重点。

**Architecture:** 保留原生 WXML 事件及 JS 控制器，用明确的浏览入口类和页面样式限制强调范围。唯一主要业务提交继续沿用既有主按钮；浏览、搜索、筛选不复用该层级。

**Tech Stack:** 原生 WXML/WXSS；现有 wcc/wcsc、浏览器渲染和小程序构建工具。

**Spec:** 用户 2026-11-10 本轮两张真机截图与明确的按钮层级要求，覆盖此前“所有主要/搜索/查看入口统一实心黑”的视觉决定。

## 设计决定

- 首页下一步使用右对齐文字入口；查看可订阅车辆使用自然宽度、白底细边框按钮，保留清楚的点击区域。
- 选车搜索为白底文字操作；品牌选中项用浅暖底、细边框与字重区别，未选中保持白底；查看方案为文字箭头。
- 底部保持四入口、选中图标、路由和动效；选中项改浅底配小面积黄色标记。
- 品牌黄色用于小标签、细标记；正文深色保持对比度。触控区域至少 44px；不以减小触控范围换取轻量视觉。
- 选择定向样式调整。未选择全站主按钮改色（会削弱提交/支付等主操作），也不重做页面结构（超出用户本轮目标）。

## 约束及检查重点

- 仅真实版 `apps/miniprogram`；原样参考副本只读。
- 不改 JS、API、金额、认证、签署、登录、路由状态。既有 1.3.0 暂停正式发布记录继续有效；本轮完成改版与本地验收包，不提交审核或正式发布。
- 当前工作区保留原状，先冻结本次源码基线；新包使用独立目录，防止覆盖其他任务产物。
- 检查 320/390/430px、长车型和金额、加载/错误/空列表、选中状态、底部安全区；浏览器结果不称为真机结果。
