# 产品、商品与换车规则实施计划

依据：10/31主设计、固定旧仓库规则核对及本聊天逐项确认。用户已授权计划后直接施工。仅本项目写入；根schema、迁移、依赖由主控整合。

## 确认规则

- 四入口共用订单、商品和冻结条款；历史订单不套用新产品权益。
- 补能首版自付；产品配置合同期赠送换车次数、额外换车单次服务费。
- 升级车辆按新旧月费差额及剩余原租期自动计算，原合同结束日不因换车延后。
- 不足月按原服务月实际天数分摊，新车实际交付日计入新车。每期四舍五入到分，先按期取整再求和；月末起租沿用原日号截至月末的边界。
- 价格和权益必须在申请/最终方案/订单/变更报价中冻结；不能用实时目录价格复核旧付款。
- 里程包每月包含公里数、里程包月费、超里程单价三项均按产品配置，历史订单保留原规则。用户已确认首版只支持同价换车或升级，降级报价直接拒绝。

## P1 产品工作台和商品（API）

- [ ] 使用版本化产品配置表达基础费、里程包、固定自付能源和换车政策；保留历史v1解析。
- [x] 发布产品仅进入仓库；具体车辆与产品版本经商品组合及显式发布后才能供新申请使用。
- [x] 商品保留兼容subscriptionPlanId，同车多商品，所有占用仍事务锁同一物理Vehicle。
- [x] 新增goods接口和权限，支持草稿、发布、下架、重新发布、检索、详情。版本冲突/同键不同内容拒绝。
- [x] 兼容迁移仅将既有真实active套餐转为等价商品，不自动展开新适配范围，不改历史订单。已在本地隔离库迁移，生产未执行。

## P2 产品和商品（后台）

- [ ] 产品工作台分模块配置与总价预览；仓库独立展示版本和启停状态。
- [x] 商品中心明确车辆、产品版本、月费、权益和发布状态，提供详情及发布/下架操作。
- [x] 商品中心保留旧入口深链、权限过滤和紧凑布局；不展示未实现的按钮。

## P3 目录、申请和履约规则

- [x] 目录仅返回当前已发布且适配的商品；提交、方案发布和客户确认重新校验商品与物理车占用。
- [ ] 最终方案快照冻结组合总价、里程参数、合同期换车政策；旧快照仍按原规则解释。
- [ ] 里程规则如配置变化，增设USAGE_V2并逐处替换硬编码，旧USAGE_V1保持1500公里/150分。
- [ ] 小程序保持视觉，显示真实商品条款；合作商H5仍仅显示本授权车辆与分润白名单。

## P4 换车计算和账本

- [x] 先以纯函数及边界测试实现已确认的升级差价算法；10项边界测试全部通过，主控已审阅。在完整变更流程接入前不生成账单、不开放旧总门禁。
- [ ] 合同期赠送账本使用TERM序号，不能沿用旧每12个月一次的年度记录；次数预占、取消释放、交付生效核销幂等。
- [ ] 单次购买价格取订单冻结政策；支付、重复到账、退款、恢复和小程序校验均兼容历史800元记录。

- [ ] FIELD支持每次换车的旧车归还与新车交付；实际日期变化重新计算且要求确认，不静默改价。新交接事实和旧记录保留。
