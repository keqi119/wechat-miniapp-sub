# 后台紧凑工作区与取消流程实施计划

> **For agentic workers:** 使用 superpowers:subagent-driven-development 按文件归属实施，或使用 executing-plans 顺序实施。

**Goal:** 一级列表和长详情将主要视口交给业务数据，交付前取消在单独分支中显示完整条件并就地办理。
