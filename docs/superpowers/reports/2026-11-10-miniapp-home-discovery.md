# 首页移除重复进度卡

2026-11-10 用户同意建议后实施。首页已移除“你的下一步”整张卡片，顺序为品牌、订阅介绍、推荐车辆、订阅指南。申请与订单进度继续从“用车”进入。

## 修改与边界

相对 `20261110-miniapp-light-controls`，仅修改首页 `index.wxml`、`index.wxss`、`index.js`：删除卡片、对应页面样式、未使用的 `openNext` 事件及初始字段。保留上轮轻量按钮、选车与底部导航样式。

首页原卡只有当前订单/申请两个目标；后台 dashboard 与首页使用同样的客户归属、状态过滤和时间排序，“用车”已有“查看本订单”“查看申请进度”。独立只读审查确认无独有入口丢失。浏览车辆、下拉刷新、错误重试、空态、FAQ 与路由未变。

API 契约保持兼容，服务端仍可返回 `nextAction`，首页不再显示。现有 `nextAction/todos` 混合等待与可执行事项，未将其直接用于新角标；保留“用车”已有待办和账单展示。未调整后台、认证、支付、签署、权限或业务流程。
