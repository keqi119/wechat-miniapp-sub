# 产品定价参考实施与验收记录

日期：2026-11-13。范围：宁达订阅管理中台产品定价参考第一版。基于已确认的 [设计](../specs/2026-11-12-product-roa-pricing-reference-design.md) 与 [计划](../plans/2026-11-13-product-roa-pricing-reference.md)。

## 交付结果

- 新增「产品中心 → 定价参考」，支持经营场景、残值曲线、单车 review 的版本化维护，以及逐车或按车型、年款、电池方式和容量分组统一定价。
- 自动按采购锚点、适用残值曲线及有效 review 推算定价日残值；基础使用费参考上限为该残值的 3.5%。剩余经营期 ROA 使用该残值作为起始资产基数，不要求额外手工填写期初资产价值。
- 逐车展示来源、缺项、成本、ROA、参考上限和目标价格；分组展示覆盖率、资产加权 ROA、逐车差异及目标价格与上限冲突。
- BaaS 作为持有成本，不乘出租率；另收客户电池费用须明确经营收入或第三方直付。保险保留已知保费，仅对缺覆盖部分补充显式预算。管理费用按预定管理规模分摊。
- 每次测算冻结参数、来源和结果。review 更正、撤回及后续补录只影响新测算，历史查看和导出不重新计算。
- 按组生成独立产品草稿，仅适用明确选中的车辆；支持幂等重试，不自动发布。修改当前输入后不可误用旧参考，历史记录须明确选择后采用。
- 财务可维护和查看参考参数；创建产品草稿另行校验既有产品写权限。内部成本与收益来源不写入客户商品或合同快照。

第一版不纳入融资、杠杆、利息、押金收益或所得税；不新增 ROA 审批与发布门槛。缺失的经营数据不按零填充，不自动采集市场残值。
