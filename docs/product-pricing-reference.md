# 产品定价参考使用说明

适用于宁达订阅管理中台「产品中心 → 定价参考」。本功能提供内部定价依据；产品发布仍执行原有流程，不新增 ROA 审批或价格审批门槛。

## 首次准备

1. 车辆资产档案补齐采购价、采购日期、首次登记日期、电池产权及容量；车型资料补齐年款。年款与车辆登记年份不是同一字段。
2. 在「场景 / 曲线 / review」中建立经营场景：先填写顶部的预定管理规模、出租率、产品期限、复购率、坏账率和预计行驶里程，必要时填写目标年化 ROA；再按三类成本卡片维护预算。成本为空表示未知；确认无此项成本才填 0，未使用的模板无需添加。
3. 按车型、年款、电池产权和容量建立残值曲线，填写适用车况、里程范围、依据与生效日期。曲线系数为正值，使用车龄月数；系统在点间插值，不自动向范围外推算。

曲线维护中的车型 ID 来自车型档案；review 的车辆 ID 来自车辆档案或本次逐车结果。参数版本详情可以查看和复制记录 ID。当前版本采用人工维护的曲线，不会自动采集市场价格或虚构市场样本。

## 选车与测算

1. 选择经营场景版本、定价日期及预计车辆退出日期。退出日期描述剩余经营期，和客户购买产品的订阅期限分别填写。
2. 筛选并选择车辆。「全选筛选结果」读取完整分页，筛选变化保留已选车辆；单次最多 1000 辆。
3. 按车型、年款、电池方式和容量生成分组。新组默认采用所选场景的产品期限；每组填写统一基础费、里程费、期限和权益。实际填写的分组期限决定该组获客、交付、回收等周期费用频次。需要逐台定价时将单车作为一组。
4. 在逐车假设中核对曲线车况适用性。可明确选用曲线，或覆盖本车退出日期、处置成本、一次性成本；合同或保险未覆盖的部分可补充有依据的费用预算。
5. 生成定价参考，查看逐车缺项、基础费参考上限、年化 ROA、组内最低/中位/最高值，以及组整体和每车分别达到目标的参考价。

没有有效采购锚点或曲线时，不生成虚假的零残值。仅退出点不足时，定价日残值和基础费上限仍可显示，ROA 保持不可用。分组指标注明可测算车辆数；不能把部分车辆的结果理解为整组完整评估。

## 经营场景的三类成本

顶部规模包括出租与闲置车辆，不是本次选择的车辆数。复购率指预计订单中老客户订单的比例；坏账率指预计经营应收租赁收入最终无法收回的比例，暂时逾期但可收回的不算坏账。

| 卡片 | 填写方式 | 计入时间及分摊 |
| --- | --- | --- |
| 随车辆发生的成本 | 使用模板或新增有名称的明细，填写原始单位金额及数量/次数；BaaS 月预算、保险年预算另列 | 持有月/年、出租月/公里、闲置月、每订阅周期分别计算；未来投放一次性与退出处置单列 |
| 企业固定经营成本 | 人员可填人数×综合月人均成本，或数量 1 填部门月总额；办公、系统、财务等按月/年填写 | 月总额÷预定管理规模，闲置也分摊；一次性企业投入明确发生日期及分摊月数，仅取评估期间的交集 |
| 订阅业务营销成本 | 固定推广总预算＋折算周期＋覆盖规模；每单新客获客成本；每单复购维护成本 | 固定推广按月均投入持续计入直至新版本调整；每单成本按产品期限及新老订单比例计算 |

同一费用只录一次。例如单车停车不要同时计入企业场地费；已包含在每单获客成本的渠道费不要再次计入固定推广预算。底部汇总从明细自动计算，不再另填一笔总成本叠加。

上海新能源牌照生成费模板为 12,000 元/车，一次性、无回收价值。只有逐车明确仍需支付未来投放费用时才计入；已支付的牌照及投放费用不因重新定价再次计算。该费用不增加定价日残值或基础费上限。退出处置费仅从退出残值扣除一次。

BaaS 合同及保险保单优先按真实期间计算；场景预算只补未覆盖部分，逐车预算优先于场景预算。保险缺覆盖年预算只填写缺失险种/期间的补充费用，不含已知保费；完全没有已知保单时填写全车年度预算。年预算保留年度口径，不替代已知保单。明确没有的费用填 0，尚不清楚的费用留空；适用的未知费用会显示缺项。

每车年度预算订阅周期数 = 12 × 出租率 ÷ 产品期限（月），允许小数。例：6 个月、90% 出租率、40% 复购、新客每单 500 元、复购每单 50 元，年营销变动成本为 1.8 × (60% × 500 + 40% × 50) = 576 元/车。交付、回收、整备按每周期预计次数计算，复购不会自动减少物理交接次数。这是未来预算分摊，不是实际订单数量预测或历史单据重新入账。

建立旧场景的新版本时，旧合计转换为有名称的明细，保留未知与 0 的区别；补齐新参数后保存。旧版本与此前生成的定价参考保持原样。

## 计算口径

- 定价日残值：以采购价或有效单车 review 为金额锚点，乘以选定曲线在目标车龄与锚点车龄的系数比值。购入二手车不会重复扣减购入前折耗；首次登记前购入的新车以 0 月车龄锚定。
- 基础费参考上限：定价日残值 × 3.5%，向下取到整数分。上限仅比较基础费，不比较含里程费的合计月费。
- 客户另付电池费用：另行收取时必须明确是经营主体收入还是客户直接支付第三方，并填写依据；未明确时 ROA 保持缺项。经营收入按月或按产品合同期精确摊为出租期间收入，车辆持有方承担的 BaaS 成本仍单独计算。
- 管理成本：预定规模下的月预算 ÷ 预定管理车辆数。分摊分母不随本次选车数量变化，也不随出租率减少。
- BaaS：车辆持有方承担的实际租金，按真实计费周期和持有区间计算，不乘出租率；已生成成本计划仅覆盖自身期间，其余签约期间仍读取合同。未知期间须明确预算。
- 保险：按已知有效版本、覆盖期间和原始保费分摊；已支付的未来期间保费仍是成本。缺失险种或期间的预算是补充费用，不抹去已知保费。多车保单无明确单车分摊依据时不自行平均。
- 剩余期利润：剩余期出租收入减变动成本、固定持有成本、规模管理分摊、一次性成本和剩余折耗。退出净残值另扣处置费用。
- 坏账：预计应收经营租赁收入 × 坏账率；预计实收为应收减坏账。适用于基础费、里程费及明确属于经营主体的其他租赁收入，不含押金或客户直付第三方款项；不减成本、残值或基础费上限。空置损失已反映在出租率中，不重复扣除。
- 期限、复购与坏账同时影响保本价和目标价。出租率为 0 或坏账率为 100% 时仍展示可计算的经营亏损，但无法通过提高价格求得保本价，页面说明原因。
- 年化 ROA：剩余期利润按持有月数年化，再除以「定价日残值与退出净残值的平均值」。组 ROA 使用合计年化利润 ÷ 合计平均资产，不直接平均单车百分比。
- 可选目标价向上取到整数分。若逐车达标目标超过组内最小基础费上限，显示冲突，不截断价格后声称满足目标。

所有输入金额应按相同资产范围和税费口径维护。第一版不计算融资杠杆、利息、ROE、押金收益或所得税；ROA 是内部经营假设下的测算结果。

## review、历史与生成草稿

review 记录估值对应日期、车龄、里程、金额、依据及生效时间。更正或撤回通过追加版本完成。单车 review 仅校准该车；需要改变车型整体衰减形状时建立曲线新版本。

生成时冻结经营场景、曲线、review、车辆和费用事实、假设、算法版本及结果。后来录入或补录的 review 不改变旧记录。历史查看和 JSON 导出直接读取原快照；「恢复原输入，准备重新测算」才建立新的测算记录。

每个分组分别保存成独立产品与草稿版本，只关联明确选中的车辆，不同时附加宽泛车型范围，不自动发布或上架。保存结果显示已保存、失败或未处理；遇到响应未知时按原内容重试，系统复用原幂等请求。修改当前输入后，旧结果不可作为新输入的采用依据；可从历史中明确选择并采用原冻结记录。

管理员、运营、财务可维护和查看定价参考；创建产品草稿还需要原有产品写权限，财务不会因此获得产品发布权限。成本、ROA 和内部来源快照不进入客户商品或合同快照。
