# 现场交接工作台

运营入口：`https://mini-admin.subauto.keybox.cloud/field.html`。公众号可将“现场交接”菜单设为跳转该网址；公众号访问本身不授予员工权限。员工必须使用后台创建的 FIELD（现场交接）账号。

## 办理顺序

1. 管理员在“后台账号”创建真实人员账号，选择“现场交接”角色。使用至少16位随机密码，凭据以私密方式交付；员工登录后在顶部“改密”，之后重新登录。
2. 后台“现场交接任务”选择订单、交车/还车、指定员工，填写预约说明。任务只分配给一位在岗员工；改派即时撤销原员工访问。订单必须处于相应交接阶段，车辆归属仍须匹配。未发布任务取消后，可选择“重新启用或重新采集”，清空草稿并重新采集；取消和原材料保留审计。订单车辆或交付批次变化也须经过此操作，不能把旧车材料用于新车。
3. 员工进入“我的现场任务”，记录实际时间、地点、里程、电量、物品、车况和未结事项，上传现场材料。时间均按北京时间；不以打开页面的时间自动认定完成交接。
4. 上传会保存当前输入；也可点“保存草稿”。刷新可恢复服务端已保存内容。网络失败时不会显示已保存，避免直接离开。支持 JPEG/PNG/PDF，10MiB/份、20份上限，发布至少一份；HEIC需先导出为JPEG。
5. 员工“核对并发布”，核实记录并明确勾选后发布。客户在小程序“用车→车辆交接”逐项打开附件、核对事实，确认或提出异议。
6. 客户提出异议后，现场人员填入处理说明、修订并重新发布。旧版、异议和摘要保留；新版重新确认和签署。发布后不能随意覆盖。
7. 后台准备交接单独立签署与逐份双人用印复核；客户本人签署。后台再按原条件执行“确认完成交接”。交车完成进入用车中，还车完成进入退订结算，押金退款和费用另按原流程办理。

## 权限与记录

- FIELD 无订单库、客户库、财务、用印或通用附件权限。仅本任务必要称呼/车辆/地点安排可见。
- 文件以任务绑定，已上传未发布文件不会向客户公开；客户发布后也只能读取本人交接证据。
- 版本冲突须刷新并核对，不能覆盖新版本。相同发布编号重试返回原交接，不重复通知。
- 后台直接接管并修订旧交接时，手机端停止编辑并提示版本变化，应由后台继续原交接流程。
- 任务发布不代表签署、交付、付款或结算完成；现场账号不能代客户确认/签署。
