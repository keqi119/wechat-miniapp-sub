# 首版指定订单验收报价

本能力仅准备用户已确认的真实订单验收报价：12期租金各0.01元，合计0.12元；押金一次性0.01元。公开车辆套餐、实际信用档位、支付回调和逐份签署复核规则不变。

## 启用前

先核对申请人、车辆、出租授权、保险与逐单条款。客户需对本申请单独授权人工信用核验，由运营核实真实档位。低于650分、无法核验、授权撤回或核验版本失效仍不能发布或确认最终方案。

数据库先运行迁移 `202610170020_acceptance_pricing`；它只新增可空的方案JSON字段，历史方案不改写。

在新系统API的私有环境配置中填写单行 `ORDER_ACCEPTANCE_SCOPE_JSON`，重启新API后生效。以下仅为格式说明，标识符必须替换为核对过的本次申请实际值，不能直接用于生产：

```json
{"applicationId":"verified-application-id","customerId":"verified-customer-id","vehicleId":"verified-vehicle-id","startDate":"2026-10-17","firstDueDate":"2026-10-17","reference":"本次逐单报价确认记录"}
```

日期必须与双方确认的起租和首期付款日期一致。实际交付延期，按已确认的延期流程处理，不将计划日期登记为已交付事实。配置不完整、格式错误或任一标识不匹配，验收价即不可用。

## 报价与确认

ADMIN在匹配申请的最终方案中选择“本单验收报价”，明确填写月费0.01元、12个月及上述日期，并填写完整逐单条款。后台显示押金0.01元，服务端重新核验配置和金额；表单不能上传或伪造授权快照。普通报价仍按真实信用档位计算押金。

客户页面和合同的押金栏列明12期各0.01元、合计0.12元及押金0.01元。客户确认前再次检查当前配置、信用同意及核验版本。确认后生成12笔1分租金账单和1笔1分押金账单，配置随后关闭不会改价或重复建立订单。

## 关闭与历史记录

清空环境变量并重启API即可关闭。关闭或改动范围后，尚未确认的验收方案不能继续确认，应重新核对；已确认的订单、合同生成和后续支付按冻结的方案处理。历史签署文件不重新生成或覆盖。

验收授权快照保留配置摘要、申请/客户/车辆/日期、管理员和时间，并纳入方案摘要。财务和客服只能读取实际应收金额，接口隐藏可反推信用档位的标准押金值。

此配置不启用商业支付或签署开关，不发起扣款或签章，也不代表车辆资料已经齐备。本次真实交车后提前还车，提前退订费用仍须逐单确认并据实记录。
