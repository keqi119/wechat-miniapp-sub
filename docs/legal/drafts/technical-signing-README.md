# 电子签署流程验证文件审阅入口

状态：用户于2026-10-16明确批准“已审阅，批准该技术验收文本；本人签署与本份文件用印另行操作”。完整批准源文件：[纯电主义电子签署流程验证确认书](technical-signing-verification-v1.md)；[正式模板](../versions/technical-signing/technical-signing-verification-v1.md)及[批准与哈希记录](../technical-signing-approval-manifest.json)另存。当前未发布，未发起签署，也未申请本文件用印。

请重点审阅以下约定：

- 用途限于验证本人签署、企业用印、状态同步、归档及本人下载。签署文件不等于确认尚未完成的步骤或整套系统已验收合格。
- 不关联车辆、租赁订单和商业报价，不产生订阅费、押金或交车义务。本次电子签署服务成本由公司承担，此前0.01元支付验证单独记录。
- 使用真实电子签名，双方完成后对本文件内容形成确认；保留信息处理、错误签署等情形下的法定权利。不能把技术验收表述为“签名不具有任何法律效力”。
- 正文只回填实名姓名和脱敏手机号。首次签署前展示具体数据用途并提供必要的单独同意；本次独立文件、同意和任务记录拟在完成或终止后保存180天，期满复核删除或匿名化，争议及法定留存按必要范围处理。其他业务仍需使用的共用实名账号、证书和授权按原适用规则处理。这是本稿待批准的新专项期限，不将技术验证当作已成交租赁合同。
- 企业章已经启用，仍需对本份填妥文件由两名实际管理员完成用印申请和复核；模板批准不等于客户本人签署或逐文件用印批准。
- 停止参与后停止新发起签署及用印；已发出的任务要核对供应商实际结果，未确认时显示待核实，不能声称本地停止已经撤销渠道签署。

逐份生成时只填入验证编号、生成时间、已核验本人姓名、脱敏手机号和签署位置；不得补入车辆、价格、租期、完整身份证号码或其他商业条款。完整填妥文件须在签署前展示，存在未解析变量时不得送签。签署时间以真实服务方记录为准，不预先填写成功结果。

接入采用独立技术验证记录，复用既有实名、签署校验及企业用印能力，不创建虚构租赁订单。正在按实施计划落实接口及页面；生产发起仍限于指定参与者和本份获批文件。

起草依据为用户本次明确用途、已批准隐私政策v2和现有双人用印流程。电子文件、保存及签名效力参考[《电子签名法》第3—8、13—14条（工信部）](https://www.miit.gov.cn/jgsj/zfs/fl/art/2022/art_e3f623f70c23497e88a941170093446a.html)；信息处理最小范围、告知、保存期限和必要单独同意参考[《个人信息保护法》第6、17、19、23、28—30条（国家网信办）](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)。180天为本稿拟定的业务保存期限，并非上述法律规定的统一期限。
