# 企业车主签约文案审阅

2026-10-17｜以下六份为完整草稿，尚未发布或替换既有合同。此次变更使实际企业车主成为新订阅合同的出租方，晓浪提供平台及电子签接入服务。

1. [企业车主认证及电子签署信息处理说明](owner-identity-v1.md)：企业经办人主动办理认证，必要身份信息加密保存；手机号认领不等于签署权限。
2. [企业车主自动签署授权说明](owner-auto-sign-v1.md)：默认手动；法大大授权与平台开关分别确认；车辆、模板、金额、期限范围及关闭方式明确。
3. [向实际出租方提供合同信息的告知与单独同意](owner-data-sharing-v1.md)：每单展示具体车主，客户另行同意，不预先勾选。
4. [车主与客户订阅合同v2](owner-rental-contract-v2.md)：实际车主与客户签约，使用车主印章；逐单填写双方、车辆、保险、日期、金额和交接资料。
5. [小程序用户协议v2](user-agreement-v2-owner.md)：客户与晓浪的服务关系，收款授权和服务分工，不把内部结算费用转嫁给客户。
6. [隐私政策v4](privacy-policy-v4-owner.md)：保留已批准v3的信用档位和交接地点说明，补充企业经办人身份、印章、授权及向具体车主提供客户签约资料。

本次审阅只批准文本或模板。具体企业认证、每份签署、车主授权范围及逐单附件仍由相关本人确认。车主结算、平台服务费系统留在下一版；不因文本批准自动开通新的收款资格或收费。

起草核对参考：[个人信息保护法](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)关于具体告知、对外提供及敏感个人信息单独同意的规定，以及本项目已批准的合同与隐私版本。实际处理范围以已实现并验证的功能为准。
