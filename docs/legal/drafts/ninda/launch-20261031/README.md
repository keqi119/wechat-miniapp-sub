# 宁达订阅：本轮上线待批文本

**本目录全部为待审候选及合成样张，未获批准、未发布，不可直接签署。** 本包不代替对真实主体、正式模板版本、具体订单及签署材料的核对。

打开 [审阅索引](index.html) 可逐项展开四份正文、查看五份完整 PDF 和全部逐页图片。[候选清单](candidate-manifest.json) 保存精确正文、类型、候选版本及哈希；[差异](changes.diff) 对照原稿正文。[样张来源索引](source-index.json) 保存最终 PDF、每页图片及实际冻结正文哈希。

## 四份正式模板候选

| 模板类型 | 精确正文 | 本轮变化 |
| --- | --- | --- |
| `usage-policy-v2` | [里程使用规则](usage-policy-v2.md) | 按真实服务阶段冻结包含里程和超额单价；原月份仍按原价结算。续期不凭空增加交车、还车；原已购里程依原有效期及适用范围办理，不自动清零、延期或恢复。 |
| `swap-credit-v2` | [额外换车单次服务费](swap-credit-v2.md) | 本次价格取购买时当前生效服务期；免费次数按新阶段重新约定，原期免费次数不结转；付费次数保留各自原价和原有效期。去除旧稿审阅说明中“本阶段 OFFLINE 关闭”的过期前提。 |
| `OFFLINE_ORDER_AMENDMENT` | [车辆订阅补充协议](offline-order-amendment.md) | 正文沿用已审通用稿，使用真实 `changeFacts`、`periodSchedule`、`financialSchedule`；本次新续期样张的取消说明来自服务端固定规则。 |
| `OFFLINE_RENEWAL_CANCELLATION` | [未开始续期取消协议](offline-renewal-cancellation.md) | 正文明确双方在新增起租日上海时间零点前同意取消并保留证据；新增实收全额原路退还、不收取消费；退款、核账和纸档可跨起租日继续，新期仍不生效，原期与原押金保持不变。 |

四类均暂标**候选版本 1**，只表示本轮审阅候选；未查询、预留或覆盖任何生产版本号。正式发布前须按该类型实际已有版本核定新版本，并保留已确认正文。`bodyRawSha256` 是原始 UTF-8 正文摘要；`applicationTemplateHash` 与应用 `hash(body)` 的 JSON 字符串摘要一致，两者有意分别记录。

本包只整理已经确认的业务规则，没有新增违约金、取消费、任意退款比例、权利放弃或法律默认。取消的“双方同意”与“签署状态核实”是不同事实，不能以开案时间或签字上传时间替代真实互认时间。原续期已激活或已有新增服务期使用的，不适用本未开始取消流程。

| 同车续期 | [续期](samples/renewal.pdf) | 全单第 13—24 期；12 期 × 200.00 元；原押金合同额 500.00 元保持。新期每月 2400 公里，2.30 元/公里，赠送 3 次、额外单次 321.00 元。固定取消规则进入本次真实冻结正文。 |
| 未开始续期取消 | [续期取消](samples/renewal-cancellation.pdf) | 有原续期签字历史，通过实际开案、互认核实及签署核实命令生成取消打印来源；本样张未准备新期账单、新增实收 0，不假造退款到账。 |

四模板先通过实际 `activateLegalTemplate` 的**纯内存**校验，随后使用当前生产业务发布器、`ArchiveContextService.resolve`、`buildOfflinePrintModel`、`renderOfflineDocument`。里程及单次换车参数替换另附 [实际渲染结果](rule-render-examples.json)，展示 2400 公里、2.30 元/公里和 321.00 元。

延期和换车的已复核状态、原 RENTAL、续期历史纸档及证据文件沿用或明确适配本项目的合成内存夹具；不表示这些事实在真实系统发生。续期经过真实预览、创建、报价、财务复核、发布和客户确认方法；取消经过真实领域命令，但没有调用真实支付、退款、最终归档或取消完成。

三方姓名取原冻结 `partiesSnapshot`，不从当前客户资料补写。原纸质合同号取实际上下文核对的归档版本；样张号码明确以 `SYNTHETIC-` 标识。三方签字、盖章及日期栏均空白。

每份 PDF 首张是**外部审阅封面**；随后为实际打印器正文，只在页顶空白边距叠加“合成审阅样张 · 未批准 · 不可直接签署”。应用正文及其哈希不被封面或标识改变。最终 PDF 完整文本已与本轮冻结正文核对，全部页脚、三方空白签署栏和逐页图片列入来源索引。打印器保留 Markdown 的 `#` / `##` 原样输出，原页码不包括外部封面。

## 旧资料与使用边界

旧批准版本、旧四稿、旧 HTML/PDF/图片/来源清单均未覆盖；本轮生成前后逐文件哈希核对。旧审阅 PDF 中的旧取消说明不用于批准本轮规则。

本包验证未构造 Db/Prisma 客户端，未连接数据库、服务器、支付或签署渠道，也未启用真实模板。日期、金额、签署状态和证据均为合成来源，不能据此判断当前生产状态。待独立审阅后，用户可针对本目录四份**精确正文**逐项作最终文本决定；本包本身不发起批准或发布。

生成脚本、输入说明、失败与成功日志、旧文件哈希清单位于项目 `tmp/admin-launch-legal-review-package/`。
