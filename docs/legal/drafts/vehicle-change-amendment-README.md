# 换车补充协议审阅入口

状态：用户于2026-10-16已明确批准模板，逐单内容另行确认。完整审阅原文：[纯电主义换车补充协议](vehicle-change-amendment-v1.md)；[已批准正式模板](../versions/vehicle-change/vehicle-change-amendment-v1.md)及[批准与哈希记录](../vehicle-change-approval-manifest.json)另存。B2换车接口完成独立验证后发布；当前未作为生产可签文本。

模板将已确认的换车规则落实到逐单协议：原剩余期限和订阅月界不变，分别记录新旧车辆仪表，基础里程与已购余额不重置；按实际完成日期确定免费周期，先免费后付费，申请及报价仅预留。车辆、差价、交接费、押金、保险、无车期间和取消安排均须运营逐单填写并由客户确认，不能使用空白或“另行通知”代替。

本次首发流程采用先还旧车再交新车，并在交旧车前核清本次应退、押金调整、交接费用及交付所在期应收；未来月份仍按原服务期和逐期到期日支付，不提前全收。该条件在模板第三条明确说明；超出能力的补偿或争议不能被系统标为已履行。

模板批准不表示批准任何具体车辆、金额、客户签署或企业用印。逐单报价、双方确认、双人用印复核、真实电子签署和真实交接仍分别执行。

核对依据为原已批准订阅合同、换车权益条款和本次明确业务答复。合同变更和明确约定参考[《民法典》第543—544条（最高人民法院）](https://www.court.gov.cn/zixun/xiangqing/233181.html)；电子文件保存及签署事实参考[《电子签名法》（工业和信息化部）](https://www.miit.gov.cn/jgsj/zfs/fl/art/2022/art_e3f623f70c23497e88a941170093446a.html)。
