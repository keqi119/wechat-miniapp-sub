## 客户告知正文

为人工审核您的车辆订阅申请并确定押金档位，经您单独同意后，运营人员核对您主动出示的本人芝麻分页面。请您自行打开页面并仅展示本次核验所需内容。我们不索取支付宝账号密码或短信验证码，不代您登录，不通过接口查询芝麻信用，不读取信用报告、借贷记录或无关交易信息。

运营人员只记录所属档位（750分及以上、700—749分、650—699分、低于650分或无法核验）、核验时间、核验人员和对应申请。不录入精确分数，不拍摄或上传芝麻分页面截图。请勿通过邮箱、工单或申请附件发送信用页面截图。

核验结果用于本次申请的押金审核，不用于营销、对外提供信用评价或其他申请的自动审核。后台根据人工确认档位计算建议押金，运营人员核对后出具最终方案，由您阅读并确认：

| 人工核验档位 | 押金 |
| --- | --- |
| 750分及以上 | 0元 |
| 700—749分 | 最终方案中1个月订阅费 |
| 650—699分 | 最终方案中2个月订阅费 |
| 低于650分或无法核验 | 转人工审核，暂不生成正式方案，不自动拒绝申请 |

以月费5,199元的套餐为例，对应押金为0元、5,199元、10,398元。核验不改变月费，不承诺授信，不授权扣款。任何金额均以您最终确认的方案及合同为准。

信用档位可能影响押金金额，也可能因页面不准确、过期或核验失误产生错误结论。您可以请求说明、更正或重新人工核验；不会只凭程序自动作出最终审核决定。不愿出示、不同意或撤回本项授权的，转人工联系处理，暂不生成正式方案；不影响公开浏览、登录及已有合同的正常查询。

结果及授权记录存放在境内业务系统，仅限履行本次审核职责的授权人员访问。未成交申请关闭后保留180天用于审核异议处理，期满复核删除或匿名化；成交后，仅将说明押金依据所必需的档位、核验记录及授权凭据随合同保存，订单结清后保留3年，未结争议或法定留存要求按隐私政策处理。原始精确分数和截图不进入系统。

您可以通过客服电话提出访问、更正、撤回同意、删除或人工复核请求，我们原则上在15个工作日内答复。撤回后停止新的核验处理；已经形成合同或争议证据的必要留存范围和理由会另行说明。
