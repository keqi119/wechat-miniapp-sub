## 使用方式

新建合同档案选用当前已启用模板。已建档案和已签合同保持固定版本；未签草稿需要采用v2时，在合同详情选择“更换模板并建立新版”，然后重新生成、预览和办理签署。已有签字材料时必须保留原记录并重新签署新版。

终止协议引用该单原实际签署合同名称、编号与相关条款，不把v2新约定追溯套入v1已签合同。填写终止原因、交回和车况、违章、应补应退及办理期限，再按生成、打印、签字版上传审核、归档顺序办理。
