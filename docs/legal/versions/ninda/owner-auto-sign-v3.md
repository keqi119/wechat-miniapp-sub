## 二、每份文件的执行条件

不设置上述产品范围限制，不改变每单交易资料的核对要求。每次用印前，平台仍核验：本单实际出租企业及车辆归属匹配；合同使用经批准的对应种类模板；实际模板编号、版本、正文和文件摘要已固定；订阅客户已确认本单完整交易条件并完成本人签署；运营已复核本份文件；企业、当前法人关系、签署证书和选用印章有效；本次操作处于授权期间，且被授权主体、文件种类与保存的授权一致。

涉及自动用印的，还须具备经确认可用的渠道自动签权限、平台自动用印能力，以及本人另行确认的启用状态。文件签署成功不替代这些条件。

车辆、月租、押金、订阅期限、费用安排和其他具体交易条件仍写入本单合同并由既有订单流程确认，不因授权表单简化而省略，也不得在客户已确认或签署后改写原文件。所选种类以外的文件须按另行开放且经明确授权的流程办理；尚未具备相应签署能力的，应等待功能开放。

## 三、单方授权书签署与自动用印权限

平台依据经审定发布的《企业车主单方用印授权书》模板和本人确认的三项范围生成完整 PDF，正文中的被授权人固定为上海宁达信息科技有限公司。文件仅设置本企业的签章位置，由法定代表人本人以本企业身份在法大大核对并手动完成电子签署；宁达无需在本次文件上签章。本流程不再调用法大大自动生成、以 API 应用所属企业为被授权人的授权委托书作为本次授权文件。

本人须核对授权企业名称、统一社会信用代码、被授权人、所选电子印章、授权期间、文件种类及完整正文。若文件与本人确认内容不符，应停止签署并联系平台处理。

发起请求、返回本页面或渠道处理成功提示，不直接代表授权书已经签署。平台须查询核对签署主体、合同编号和交易编号，确认签署结果并取得签后文件归档后，才显示“授权书已签署”。

**业务授权书签署与渠道自动签权限是两项独立事项。** 普通 PDF 文件签署成功，不表示法大大接口已授予自动签权限；平台不会据此直接记为渠道已授权或开启自动盖章。当前本流程先完成授权书签署及归档，自动用印尚未开放。后续如具备相应渠道能力，须按届时明确的办理流程核验权限，并由本人另行确认启用；运营人员不能代本人确认。

对于具体订单，逐份手动签署须按已开放的独立流程，由本人核对该份完整文件后办理。已经发送用印请求或渠道结果不明的，须先核验原交易，不并行重复签署。
