一、订阅月与起租日

订阅费按月预付，最短订阅期为12个月。每个订阅月以双方确认的实际交车日起算，采用北京时间的自然日期：包含本期起始日，不包含下一期起始日。例如10月16日起租，第一期为10月16日至11月15日，第二期从11月16日开始。原起租日期在某月不存在时，该月起始日取当月最后一天；以后各期仍以原起租日的日号计算，不逐月向前漂移。每期实际日期在账单和里程页面列示。

实际交车日晚于原约定日期时，双方先确认变更后的起租日、合同日期、费用及账单安排，再完成交车。不得先按原计划日期扣减客户的服务天数或里程。

二、基础里程和费用承担

每个订阅月包含1,500公里，先抵扣当期基础里程，再抵扣适用的已购买里程包。**基础里程在每个订阅月结束时清零，未用部分不结转。**客户在已按月预付的某一期中途退订，该期仍享有完整1,500公里，不按使用天数减少。该规则不表示预付租金一律不退；租金及提前终止费用仍按逐单签署的费用附件、实际履行情况及适用法律结算。

电池租赁费由产品提供方承担，不另向客户收取。充电及换电所发生的电费由客户自行承担。停车、通行、违章等费用按合同及责任归属处理。

已到账里程包可用于抵扣购买当期已经产生但尚未结算的超里程，也可用于之后的订阅月。**已结算月份不因之后加购而追溯重算；之后购买的包不能用于更早订阅月。**同一订单内适用的包按到账先后使用，保留发放、使用、失效记录。客户应在拟抵扣月份结算前完成购买。

四、每月申报及审核

客户应在每个订阅月截止时提交仪表累计里程及能核对读数的照片，由运营人员审核。交车、换车、还车时的读数分别记录并确认。读数应真实反映对应时点；迟交的材料须能证明该期截止时的读数，不能把后来读数直接冒充月末读数。

缺报、照片不清或材料有冲突时，先补充核实，暂停该期里程费用结算。平台不将跨月总里程自行平均分摊，也不因缺报直接视为客户已用尽里程。客户可以对读数或审核结果提出异议；更正保留原记录与核验依据。

五、超里程结算

每期实际使用里程，根据该期起止时点经核验的累计读数以及已确认的车辆交接记录计算。先扣除当期1,500公里，再使用适用的里程包；不足部分按**1.50元/公里**计算，金额以人民币分记账，不重复计费。比如某期实际使用2,800公里，基础抵扣1,500公里，适用包抵扣1,000公里，剩余300公里对应450元。

运营完成读数审核后，由财务确认结算明细和收费账单。客户可以查询期间、读数、基础额度、包抵扣及剩余收费依据，并主动支付应付账单。平台不因生成超里程账单自动扣款或直接扣除押金；争议部分先核实处理。

六、退订、交还与权益失效

退订须确认实际还车日、车辆交接和待结事项。完成还车后停止新增使用和加购，现有权益仅用于核对、结清还车前已经发生且符合适用期间的使用；不延长客户可用车或购买的期限。缺少月界证据的期间仍须先补证，不能通过直接关闭订单跳过结算。

**退订后未使用的加购里程及加购换车次数失效，不退还相应未使用权益的购买费用。**这项规则会在每次购买前显著提示，并由客户另行主动确认。因服务提供方未按约履行、错误收费、重复付款、权益未到账等原因产生的退款或争议，应按实际情况和适用法律处理；本条不免除服务提供方依法应承担的责任，也不排除客户依法主张退款、赔偿或投诉的权利。

物理还车与财务结清分别记录。未来尚未履行的账单及已收费用需按双方确认的结算处理；有待核实付款、待退款或争议时不能标记已全部结清。无争议押金余额退款继续按主合同约定办理，不以未使用权益失效为由没收押金。

七、换车权益

每个12个月订阅周期包含1次免费换车权益，未使用次数在该周期结束时清零，不累积到下一周期；下一周期重新计算1次。加购换车权益为800元/次，可叠加，限当前订阅期内使用，退订失效及费用处理按上述特别提示。

换车权益用于抵扣约定的换车次数，不代表任意车型免费升级或免除所有交接费用。运营应逐次给出可交付车辆、月费差额、交接费用和补充协议，客户确认并完成必要签署后安排换车。换车后原合同剩余期限不变；新旧车辆读数分别记录，不以直接修改车辆名称替代交接与费用确认。
