# 宁达项目上下文

记录于 2026-11-02，仅在宁达车辆订阅项目使用；最新用户决定、项目约束与 `docs/api-contract.md` 优先于本摘要。应用规则改变时更新此文件，不传播成其他项目的默认规则。

- 现有客户入口：**首页、选车、用车、我的**。黄白为当前品牌基础，强调色 `#F9BE00`、主文字 `#231815`。PC 后台蓝色主按钮要求不能自动套到客户小程序。
- 当前真实代码在 `apps/miniprogram/src/`。`reference/miniprogram-mock/` 为只读原样副本。仅视觉探索时不改真实页面；用户已于 2026-11-02 选定“明朗原生”并授权实现、提交体验版 1.2.2，本版未授权生产提审或发布。
- 同车可有多个产品商品，客户在车辆详情选择已发布可售方案。费用需区分基础月费、里程包月费、押金、包含公里数和超里程单价；充换电自付，不能画出尚未开放的补能赠送权益。
- 赠送换车次数按服务期产品配置，额外单次服务费与升级差价分开；首版支持同价/升级，不画可直接降级退款的入口。
- 续期追加原订单服务期，按新商品方案报价。界面不能暗示原月份里程被重置或赠送次数自动结转。
- 微信登录、资料上传和人工审核不等于线上实名认证。线上实名暂缓；适用文案是“资料待审核/资料已审核”，不得据此显示“实名认证成功”。
- 账单明确标注押金、首期租金、后续期租金等事由与适用服务期。付款成功和实际车辆交付是不同事实。
- 四类交接（交车、还车、换车收回、换车交付）采用线上记录：现场提交证据 → 客户本人确认 → 后台核对实际完成。已确认、已完成、被替代版本保持只读，隐藏再次勾选与提交入口。主租赁合同及变更补充协议仍独立签署；旧纸档仍可查看。
- 管理员可自审普通资料；退款和资金事项仍独立复核。界面简化不能跳过服务端权限与审批规则。
- 原型使用合成金额与记录，车图标明车型示意；避免展示真实客户证件、手机号、VIN、签名或付款信息。

已选规范：明朗原生（品牌延续与费用清晰）。采用白色导航与内容分组、浅灰页面、黄黑主操作、清楚的费用分项；具体实现记录见 `docs/superpowers/specs/2026-11-02-miniapp-bright-native-design.md`。静奢出行和轻盈城市保留为未选提案。
